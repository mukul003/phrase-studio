# Topic-only script prompt

Change only the topic on the first line. The live app can fill it automatically.

```text
TOPIC: [REPLACE ONLY THIS TOPIC]

Create a complete English-speaking practice script for Fluent English For You about the topic above.

Audience: adult beginners and working professionals. Include exactly 10 useful, easy-to-say sentences. Make the lesson feel like a relaxed conversation with one friend. Use simple English, contractions, short sentences and a warm tone. Keep situations believable and each example logically connected to its sentence.

Write a friendly intro that starts with a relatable situation from the topic and naturally invites the listener to practise. For each sentence, give a short summary explaining its meaning and when to use it, one natural example, and a brief invitation to speak. Vary the invitations gently. End with a friendly outro that encourages using one sentence today. Keep the finished lesson comfortable to read aloud, around 4–6 minutes including viewer speaking pauses.

Use the labels below on separate lines. Labels are for the app and are not spoken. Write each sentence and example once; the recorder controls repetitions. Do not include stage directions, timestamps, countdowns, sound effects, tables, Markdown formatting, alternative versions or commentary outside the script. Do not invent personal claims for the narrator.

Return this format, with all 10 complete Sentence/Summary/Example/Cue blocks:

Title: [short descriptive title]
Intro: [complete conversational introduction]

Sentence 1: [sentence]
Summary: [short meaning and when to use it]
Example: [complete natural spoken example]
Cue: [brief invitation to say the sentence]

Continue the same four labels for Sentence 2 through Sentence 10. Replace every placeholder with finished spoken text. Do not print this instruction.

Outro: [complete friendly closing]
```
